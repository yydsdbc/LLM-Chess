### Added
- **Round-48 batch** (2026-09-24, 15 items): **a guard that could be walked around, a relay request that never answered, and one rule with two disagreeing implementations.** (1) **The static denylist added in round 47 was bypassable.** It matched the **raw** first path segment, and `path.normalize` runs afterwards, so any innocuous first segment hides a traversal: `GET /x/..%5cconfig/keys.json` (`%5c` decodes to a backslash, and browsers do not treat `%5c` as a separator, so it arrives intact) has raw first segment `x`, yet normalises to `ROOT/config/keys.json` — inside `ROOT`, so the prefix check passes too. Verified live: **HTTP 200 with the key file verbatim**. The check now runs on the normalised relative path, segment by segment, and is platform-independent (on Linux the same string is merely a filename, which is why the hole only lived on Windows deployments). (2) **A non-stream relay request whose upstream died mid-body never answered at all.** The `!wantStream` branch (and the Anthropic path) had only `data`/`end` listeners, so a socket destroyed after the headers and half the body produced neither `end` nor a handled error — measured **12s of complete silence** before the client gave up, instead of the 502 that a *failed connection* already produced (round 45 covered only the connect step). Notably this was a hang, not a crash: Node emits `error` on a client response **only when a listener exists** (verified in isolation — no listener yields just `aborted` + `close`), so nothing ever threw and nothing ever finished. Both paths now settle through a single idempotent outlet keyed on `upRes.complete`, and both answer 502 in ~50ms. The same handlers gained a **16MB cap** on non-stream upstream bodies, which previously accumulated without limit. (3) **Routing used the raw `req.url`**, so any query string — `POST /api/chat?t=1`, `GET /api/health?x=1` — missed the API branches entirely and fell into the static handler, answering 404; the front end saw "404 Not Found" instead of the real relay result. Routing now uses the pathname only. **One rule, two implementations, disagreeing** — `applyPlayerMove` maintained the long-check counter and the natural-move clock incrementally with `st.result === 'check'`, while the pure `replayStats`/`checkStreaksFrom` replayed with `Rules.inCheck`; `Judge.status` reports **`checkmate`**, not `check`, so a mating move was treated as an ordinary move: the streak was **cleared** where the documented intent (and the replay path) says +1, and the natural clock counted a check. Measured over 60 random games: **21 of 16951 plies disagreed, every one of them a mate.** That divergence mattered beyond the on-board reading, because it made the next item unsafe. **Undo was O(n) per ply** — `undoPly` recomputed the stats by replaying the whole history from `genesis`, so clicking move #1 in a 489-ply log cost roughly 240k `applyMove` calls, each with a full attack scan. The stats now ride a per-ply snapshot stack (O(1) per undo, O(n) per jump; measured 19x at n=93 and 49x at n=235, growing linearly with length), with the replay recompute kept as a fallback if the stack/history invariant is ever broken. **The first version of that stack was wrong and the equivalence probe caught it immediately**: it restored the popped entry — the state *after* the move being undone — instead of peeking at the previous one, which showed up as 318/320 undo steps disagreeing with the replay. **a11y / focus** — four more places where hiding or disabling a focused control dropped focus to `<body>`, the same class rounds 42-47 fixed one container at a time: `#btn-row` going `visibility:hidden` when a game ends and restarts (a keyboard user tabbing to "Restart" and pressing Enter lost their place), the replay restore button hiding **the very bar it lives in**, `syncArchive()` disabling `#btn-save`/`#btn-undo` (the capture must happen *before* the assignment — the round-47 lesson), and `rpClose()` restoring focus to an opener that had since hidden itself (the last-move badge auto-hides after 4s, and `focus()` on an unfocusable element is a silent no-op — now verified by checking that focus actually landed). The runtime banner was focusable in warn/err mode with **no role at all**, so a screen reader never announced that Enter/Space dismisses it; its `role` now tracks the same `dismissable` predicate as its `tabIndex`. The replay move list's high-speed path moved only the `.active` class, leaving `aria-current` up to four plies behind the visual current move (and re-scanning every entry per step to do it) — it now carries a tracked reference and moves both. **i18n** — the provider test-connection result called `T2('test_ok', { ms })` where `T2` was the **one-argument** `t`, so the UI literally displayed `✓ 连通 {ms}ms` in both languages and never showed the latency; it now uses `tArgs`. Two surfaces written imperatively (and therefore invisible to declarative refresh) went stale on a language hot-swap: `#server-warn`, which lives *inside* the settings dialog where the language selector is — and being a live region, it re-announced the old language — and the end-game stats block plus its "replay this game" button. **PWA** — the service worker's `activate` deleted **every cache whose name was not its own**, which on the documented GitHub Pages deployment (`<user>.github.io`, shared by all of that user's project pages) wipes a sibling app's offline shell; it now filters on its own `xq-shell-` prefix, so old versions are still cleaned up. **Guards** — `check_ui` gains **section 22** (26 anchored checks), `_logic_layer` gains **L20** (9 behavioural assertions) and `_server_http` goes **108 → 119** (run on a second server instance, because the per-minute rate-limit window was already saturated at exactly 30/30 by the existing suite); **19 mutation probes** all fire red with byte-identical restoration.
